# Supplementary Materials: A Two-Stage Clustered MILP Framework for Efficient and Resilient Waste Collection Routing

**ICERIE 2027, Paper ID 87**

**Authors:** Riasad Rahman Rakib, Hasin Almas Sanim, Md. Mohibul Islam  
**Department:** Industrial and Production Engineering, RUET

This repository contains supplementary materials that could not be included in the conference paper. The materials are based on the extended case study report (RUET IPE, April 2026). No new results have been added.

## Files

| File | Contents |
|---|---|
| `Supplementary_Materials.pdf` | Dataset, cluster results, full MILP formulation, scenario results, sensitivity results, and reproducibility notes |
| `Supplementary_Materials.tex` | LaTeX source |
| `figs/` | Original figures from the full paper (Fig. S1–S4) |
| `01_Comparison_Report.md` | Comparison of the conference paper and supplementary materials |
